# Data Cleaning Project – Iris Dataset

## Project Overview

This project focuses on identifying and cleaning common data quality issues in a public Iris dataset using Python and Pandas.

## Data Quality Issues Identified

The dataset was checked for:

- Missing values
- Duplicate records
- Incorrect data types
- Inconsistent values

## Data Cleaning Performed

The following cleaning steps were performed:

1. Identified and handled missing values.
2. Removed duplicate records.
3. Corrected incorrect data types.
4. Standardized inconsistent values.
5. Saved the cleaned dataset as `cleaned_dataset.csv`.

## Files Included

- `data_cleaning.py` – Python script used for data cleaning.
- `raw_dataset_with_issues.csv` – Dataset containing the identified data quality issues.
- `cleaned_dataset.csv` – Final cleaned dataset.
- `README.md` – Project documentation.

## Tools Used

- Python
- Pandas
- CSV

## Objective

The objective of this project is to demonstrate basic data cleaning and preprocessing skills required for data analysis.
